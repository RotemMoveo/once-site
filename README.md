# ONCE

אתר ONCE — האתר החי, העיצובים והחומרים שנוצרו לאורך הפרויקט.

**האתר באוויר:** https://rotemmoveo.github.io/once-site/

## מבנה

| נתיב | מה יש שם |
| --- | --- |
| `גלי/ONCE site/` | **האתר החי.** זו גרסת האמת — כל תיקון נעשה כאן. זהו גם התוכן שמתפרסם ב-GitHub Pages. |
| `גלי/ONCE site/_en-build/` | סקריפט הבנייה של הגרסה האנגלית. `en/` נוצרת ממנו ואין לערוך אותה ידנית. |
| `גלי/ONCE site/_spec-build/` | סקריפט הבנייה של עמוד המפרט הטכני. |
| `רתם/` | עיצובים, גרסאות והתלבטויות — שלוש גרסאות ל-404, שתיים ל-צור קשר, מספר גרסאות לעמוד אודות, ה-styleguide. ארכיון, לא קוד חי. |
| `ONCE — מדריך שפה צילומית.pdf` | המדריך ללקוח על כתיבת פרומפטים ל-Ai עבור צילומי בניינים בשפת המותג. |
| `תוכן - אתר ONCE.xlsx` | גיליון התוכן מהלקוח. |

## עמודי האתר

עברית: `index` · `about` · `projects` · `project` · `urban-renewal` · `kablanit` · `news` · `article` · `contact` · `search` · `spec` · `accessibility` · `privacy` · `404`
אנגלית: אותם עמודים תחת `en/`.

בנוסף: עמודי מצב לטפסים (`*-success`, `*-error`) ופופאפ הליד (`popup`).

## פרסום עדכון

האתר מתפרסם מענף `gh-pages`, שהשורש שלו הוא התוכן של `גלי/ONCE site`.
אחרי שינוי באתר, מריצים:

```bash
./deploy.sh
```
